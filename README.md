## 💻 Programs

This repository contains **16 code book  programs** based on advanced Object-Oriented Programming concepts including function overloading, operator overloading, inheritance, polymorphism, abstraction, virtual functions, and smart pointers.

### 01. Function Overloading

Demonstrates function overloading by defining multiple functions with the same name but different parameters. The program also demonstrates string concatenation using an overloaded function.

### 02. Area Calculation Using Function Overloading

Demonstrates function overloading to calculate the areas of different shapes such as square, rectangle, circle, and triangle.

### 03. Unary Minus Operator Overloading

Demonstrates unary operator overloading by overloading the unary minus (`-`) operator for a number and a balance.

### 04. Prefix and Postfix Increment and Decrement

Demonstrates operator overloading for prefix and postfix increment (`++`) and decrement (`--`) operators using a Counter class.

### 05. Binary Minus Operator Overloading

Demonstrates binary operator overloading by subtracting two complex numbers using the overloaded `-` operator.

### 06. Equality Operator Overloading

Demonstrates overloading of the equality (`==`) operator to compare two Distance objects.

### 07. Friend Operator Overloading

Demonstrates friend function operator overloading for performing operations between an integer and a complex number.

### 08. Function Overriding Using Inheritance

Demonstrates function overriding using a base class and a derived class. It also shows the difference between calling a non-virtual function through a base pointer and directly through a derived object.

### 09. Runtime Polymorphism Using Animal Classes

Demonstrates runtime polymorphism using a base `Animal` class and derived classes such as `Dog`, `Cat`, and `Cow` with virtual functions.

### 10. Runtime Polymorphism Using Shapes

Demonstrates runtime polymorphism using a base `Shape` class and derived classes such as `Rectangle` and `Circle` to calculate their respective areas.

### 11. Abstract Shape Class

Demonstrates abstraction using an abstract `Shape` class with a pure virtual function. Rectangle and Triangle classes implement their respective area calculations.

### 12. Vector of Polymorphic Shapes

Demonstrates polymorphism by storing different shape objects such as Rectangle, Circle, and Triangle in a vector using `std::unique_ptr`.

### 13. Virtual Destructor and Smart Pointers

Demonstrates the use of virtual destructors and `std::unique_ptr` for safe and automatic memory management in an inheritance hierarchy.

### 14. Passing Objects by Value, Reference, and Pointer

Demonstrates passing objects by value, reference, and pointer. The program shows object slicing with pass-by-value and preservation of polymorphism with references and pointers.

### 15. Payment Processing Using Polymorphism

Demonstrates runtime polymorphism using an abstract `Payment` class and derived classes such as Card Payment, UPI Payment, Net Banking Payment, and Wallet Payment.

### 16. Employee Payroll System

Implements an employee payroll system using an abstract base class and derived classes such as Permanent Employee, Contract Employee, and Freelance Employee. The program also demonstrates tax calculation, smart pointers, vectors, and total payroll calculation.
